# 1994 DSAT RDP model extraction from *Development and validation of no-stop decompression procedures for recreational diving: The DSAT Recreational Dive Planner*

This note extracts the model as described in the uploaded 1994 DSAT report itself (pages 19–23 of the report body).

## 1. Scope of the model

The report states that the RDP development had the following objectives:
- recreational no-stop diving tables,
- repetitive procedures for no-stop dives,
- procedures for multilevel dives,
- presentation as standard tables and as "The Wheel",
- validation with human volunteers,
- reporting of results.

## 2. Native first-dive no-stop model

### 2.1 Native units
The model is expressed in **fsw** (feet of sea water).

### 2.2 Smoothed first-dive no-stop curve
The no-stop curve is given in page 20 as

\[
D - A = C t^{-x}
\]

where:
- `D` = depth in fsw,
- `t` = allowable no-stop time in minutes,
- `A = 20.15` fsw (shallow asymptote),
- `C = 803`,
- `x = 0.7476`.

Equivalent solve-for-time form:

\[
t(D) = \left(\frac{C}{D-A}\right)^{1/x}
\]
for `D > A`.

The report also states a deep asymptote of 262 fsw, included only for completeness.

### 2.3 Table II values generated from the smoothed curve
Table II lists the RDP no-stop values at:
- 40 fsw -> 140 min
- 50 fsw -> 80 min
- 60 fsw -> 55 min
- 70 fsw -> 40 min
- 80 fsw -> 30 min
- 90 fsw -> 25 min
- 100 fsw -> 20 min
- 110 fsw -> 17 min
- 120 fsw -> 14 min
- 130 fsw -> 12 min

These are the native first-dive RDP anchor values in the report.

## 3. 14-compartment parameterization

### 3.1 Half-times
The final RDP half-time set is:

`[5, 10, 20, 30, 40, 60, 80, 100, 120, 160, 200, 240, 360, 480]` minutes.

The report notes that compartments longer than 200 min are never controlling in recreational diving, but remain in the algorithm.

### 3.3 Timed-descent convention for M0 calculation
The report is explicit that for the RDP these M0 values were calculated assuming:
- a descent at **60 fsw/min**,
- descent begins at the **beginning of bottom time**,
- bottom time ends at the **end of time on bottom**,
- a **timed descent** was used, not an instantaneous one.

It also distinguishes these RDP values from the `square` column and from the earlier `Blue Book` values.

### 3.4 Inert-gas ratio note
The report says slight discrepancies between earlier values and the modern Table III values are due to the inert-gas ratio factor `0.79` vs `0.791`.

## 4. Repetitive-diving layer

The report states that the RDP uses a scheme similar to the USN repetitive framework, but with important modifications:

1. The limiting half-time for repetitive diving is **60 min**, not 120 min.
2. This choice was obtained by **iterative calculations using the entire half-time set and the RDP M-values**, checking all reasonable dive ranges.
3. The 40 min half-time was tested earlier but found not sufficiently limiting for long shallow sequences.
4. The RDP divides possible excess gas loading evenly into **26 repetitive groups**, using the entire alphabet.
5. RDP values are displayed to the **nearest minute** rather than 5-minute increments.

### 4.1 Reconstructed repetitive algorithm
The report describes the method procedurally rather than as a single closed formula. The natural reconstruction is:

- simulate a first no-stop dive with the full RDP model,
- measure the resulting residual loading using the 60-minute limiting compartment,
- quantize the possible excess-loading range evenly into 26 groups A–Z,
- during a surface interval, decay the 60-minute loading exponentially,
- reassign a new group after the interval,
- for a next dive at depth `D`, compute the **residual nitrogen time** / penalty time as the equivalent time at `D` required to reach the same 60-minute loading.

The report does not print a single symbolic formula for the group boundaries, but it does specify the governing compartment, the even 26-way partition, and the fact that the scheme was generated by iterative calculations using the entire model.

## 5. Multilevel-diving layer

The report says multilevel diving was the last modification of the Haldane algorithm for the RDP.

The multilevel procedure is described as:
- spend time at an initial depth,
- ascend to one or more shallower depths,
- limit exposure by empirically determined ascent constraints,
- use the M-values derived from the no-stop limits,
- use gas loadings in a way similar to repetitive diving,
- define the groups by iterative calculations.

### 5.1 Table IV range limits for second level
The report gives the following restrictions for the next level:

| Range of first depths (fsw) | Maximum depth of next level (fsw) |
|---|---:|
| 140–120 | 80 |
| 110–95 | 70 |
| 90–80 | 60 |
| 75–65 | 50 |
| 60–50 | 40 |

Additional explicit rules:
- all depths after the first must be shallower than the previous depth,
- calculations provide at least **5 minutes** at any subsequent level,
- ascent times are **not included** in time spent at a given level,
- multilevel information is provided only with **The Wheel**, not the flat tables.

## 6. Flying after diving / altitude

The report states:
- the flat RDP does **not calculate** for flying after diving or diving at altitude,
- instructions say the planner is usable to an altitude of **1000 ft**,
- RDP-specific corrections are available for dives planned above 1000 ft,
- both the Wheel and table include flying-after-diving procedures printed on them.

## 7. The Wheel and operational overlays

The report states that:
- "RDP" strictly refers to the computational method,
- "The Wheel" is a method of implementing it,
- the flat table gives the same RDP results as The Wheel, but is limited to **10 fsw depth increments** and fixed times,
- The Wheel uses Side One for NDL and PG, and Side Two for surface-interval credit.

Operational overlays printed in the report:
- if the table bottom time is exceeded by no more than 5 min: stop 8 min at 15 fsw, then stay out of water 6 h,
- if exceeded by more than 5 min: stop 15 min at 15 fsw, no diving for 24 h,
- safety stop: 3 min at 15 fsw when within 3 pressure groups of a no-stop limit and for any dive to 100 fsw or deeper.
