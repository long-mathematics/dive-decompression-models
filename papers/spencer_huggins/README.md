# Spencer–Huggins reconstruction manuscript

Author: Christopher D. Long.

[LaTeX source](spencer_huggins_reconstruction.tex) · [Model and scope](../../models/huggins_1981/README.md)

Build from the repository root:

```bash
sh papers/spencer_huggins/build.sh
```

The build produces `output/pdf/spencer_huggins_reconstruction.pdf`. The compiled PDF is also supplied in the accompanying research distribution.

**Status:** Version 1.0, source-preserving reconstruction and internal numerical/mathematical audit. The original HP-67 table-generation routine has not been recovered. Exact recovery of every printed rounding/operational choice and physiological validation are not claimed.

The source transcriptions retain the two numerical discrepancies. Columns J/K absent from the 1981 scan use the author's clearly identified 1987 reproduction. Fifteen tests pass; an integer/rational certificate verifies 5,988 narrowly specified compartment inequalities.
